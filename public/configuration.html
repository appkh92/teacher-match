Configuration incomplète

Le serveur fonctionne, mais l'application reste fermée tant que les variables obligatoires ne sont pas renseignées dans Railway (service → onglet Variables) :

  • DATABASE_URL : référence vers la base PostgreSQL du projet ;
  • APP_PASSWORD : mot de passe d'accès, 12 caractères minimum.

Le détail du problème figure dans les journaux du service (onglet Deployments → View logs). Railway redéploie automatiquement après l'ajout d'une variable.
